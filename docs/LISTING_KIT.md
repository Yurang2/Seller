# 상세페이지 키트 (구매대행 · 스마트스토어) · 2026-09-19

앱의 상품 화면 "상세페이지 초안"이 이 키트를 기록 값으로 채워 만든다. 기록에 없는 값은 `[확인 필요]`로 남는다(미확인은 0이 아니다). 작성 절차는 앱의 업무 절차 "상세페이지 만들기 (수동)".

## 1. 구조 (위에서 아래로)

1. 핵심 5줄: 용도 한 줄 · 소재·구성 · 크기·무게 · 배송(구매대행·기간·통관부호) · 반품(7일·반송비 실비)
2. 옵션 표기: 옵션명 · 치수(mm) · 무게(g). 옵션명은 채널 옵션과 글자까지 같게
3. 스펙 표: 상품명 / 카테고리 / 옵션 방식 / 소재 / 크기 / 무게 / 원산지 중국 / 연령 표시(성인용) / 판매가 / 배송비
4. 사용 장면 설명 2~3문단(직접 작성)
5. 고지 블록(필수, 텍스트 + 이미지 1장)

## 2. 고지 블록 표준 문구

- 이 상품은 해외구매대행 상품입니다. 주문 후 해외 판매처에서 구매하여 국내로 배송되며, 수취인 명의로 통관됩니다.
- 통관을 위해 개인통관고유부호가 필요합니다. 주문 시 정확히 입력해 주세요(불일치 시 통관 지연·반송).
- 원산지: 중국 (해외 판매처 표기 기준).
- 배송 기간: 결제일 기준 [확인 필요]일 (해외 발송·통관 사정에 따라 지연될 수 있음).
- 미화 150달러(합산 기준) 초과 시 관·부가세가 발생할 수 있으며 수취인 부담입니다.
- (섬유·가죽·반려동물 매트 등) 이 제품은 해외구매대행 상품으로 국내 KC 인증을 받지 않았습니다(전기용품 및 생활용품 안전관리법에 따른 구매대행 표시 특례).
- (운동 소품) 본 제품은 운동 보조 용품이며 의료기기가 아닙니다. 질병의 치료·예방 효과가 없습니다.
- 청약철회: 상품 수령 후 7일 이내 가능. 단순 변심 반품 시 해외 반송비 실비가 부과됩니다(반품 전 문의 필수). 제품 하자·오배송은 판매자 부담.
- 통관 완료·수취인 명의 배송 특성상 개봉·사용 후, 택 제거 후, 세트 구성품 분실 시 반품이 제한될 수 있습니다.

근거: 전자상거래 등에서의 소비자보호에 관한 법률 제13조(표시·고지), 제17조(청약철회), 제18조 제9항(반환 비용 외 위약금·보관료 청구 금지); 전기용품 및 생활용품 안전관리법 시행규칙(구매대행 KC 표시 특례·고지); 관세법 시행규칙 제45조(자가사용 목록통관 미화 150달러).

## 3. 금지 표현

- 브랜드명·캐릭터명 병기('○○ 스타일', '△△ 대체품')
- 최상급·단정 표현('최고', '1위', '100%')과 근거 없는 수치
- 의료·건강 효능('치료', '근막 이완 효과', '혈액순환 개선', '다이어트')
- KC 인증·정품 보증 문구(인증받지 않은 제품에 KC·정품 표기 금지)
- 어린이·유아 대상 연상 문구·연령 표기(성인용 상품군 전제)
- 공급처 상세 이미지·문구 복사(허락 없는 이미지 무단 사용)

## 4. 이미지 체크리스트

- 대표 1장: 흰 배경, 상품 전체, 텍스트 없음(1000×1000 이상)
- 실물 4~6장: 정면·측면·뒷면·디테일·크기 비교, 구성품 전체
- 사용 장면 1~2장
- 사이즈 도해 1장(mm·g)
- 고지 블록 이미지 1장
- 공급처 이미지 사용 시 허락 캡처를 listing_assets 항목 근거로 첨부

## 5. 상품명 규칙

50자 이내 · 브랜드명 없음 · '용도 + 핵심 스펙 + 옵션' 순서 · 채널 금지어 없음. 예: "접이식 알루미늄 노트북 거치대 6단 각도조절 휴대용 실버"
